# 파인딩 레드 (FINDING RED)

추억의 모바일 FPS 감성을 살린 Roblox 협동 게임. 스테이지마다 레드를 찾아 처치하고, 다른 몬스터는 피하거나 밀쳐내며 도장 3개를 모은다. 1~4인 협동.

- 개발 계약서: [`docs/CONTRACT.md`](docs/CONTRACT.md) — 모든 작업의 기준 문서
- 에이전트 보고서: `docs/reports/`

## 빌드

```sh
rojo build -o FindingRed.rbxl   # Studio에서 열기
tools/check.sh                  # 빌드 + 타입 검사 + Lune 테스트
```

# 원작 플레이 관찰 기록

원작(2013 모바일 FPS) 플레이 영상 두 편(레벨 1-1~2-2, 2-3~3-1, 약 12분)을 보고 정리한 **문법** 기록. 배치·그림·문구는 베끼지 않는다. 느낌과 구조만 참고한다.

## 판 구조
- 한 판 30초~2분. 벽으로 둘러싼 100스터드 안팎의 작은 경기장. 판 사이 로딩 수 초.
- 목표 수가 1, 2, 3, ... 으로 올라간다 (1-1 = 1마리, 1-2 = 2, 1-3 = 3, 2-1 = 5, 2-4 = 8).
- 레벨마다 스테이지 5개 + 보너스 1개 (넓은 초원에서 닭 같은 작은 동물 8마리 잡기).
- 시작 지점 앞에 칠판: "LEVEL x-y / 목표 n마리 잡기 / 힌트 한 줄".
- 결과: "미션 성공!!" + 도장 1~3개 찍히는 연출 + "다시하기 / 다음". 도장 2개만 받는 판도 흔함.
- 낮/밤 하늘이 스테이지마다 바뀜.

## 맵 문법
- 바닥: 회색 타일. 외벽: 파란 격자 유리벽, 남색 벽.
- 내부: 벽돌 벽(낮음/높음), 콘크리트·대리석 블록, 나무 상자, 빨간 드럼통, 카툰 나무, 계단, 옥상, 다리.
- 높낮이가 많다. 벽 위를 걸어 다니는 통로, 계단으로 올라가는 플랫폼, 높은 곳의 목표 → 저격.
- 미로형 벽돌 통로 스테이지도 있다 (후반).

## 몬스터
- 목표: 각진 사람형, 원색 몸, 빨간 눈, 이빨. 체력바가 머리 위.
- 비목표 흰색 사람형 (바이저 헬멧 느낌). 발견하면 머리 위 "!" → 다가와 공격.
- 걸어다니는 폭탄 (둥근 몸 + 화난 눈 + 다리).
- 랩터 (피격 시 화면 전체 빨개짐). 랩터에 탄 목표.
- 총알 모양 몬스터가 공중을 날아다님.
- 목표는 대체로 자기 구역(방·플랫폼) 안에서 움직인다. 울타리 안에 비목표를 여러 마리 가둬 둔 장면도 있음.

## 무기
- 기본: 방망이 + 권총.
- 맵 바닥에 무기가 놓여 있음: 저격총, AK, 샷건, RPG, 막대 수류탄. 주워서 사용.
- 상점 따로 있음 (칠판에 "상점에서 무기를 살 수 있다" 류 안내).

## 기믹
- 열쇠 → 같은 색 열쇠구멍 문. 먹은 열쇠는 HUD 왼쪽 위에 작은 아이콘.
- 손 아이콘이 뜨는 문(상호작용으로 열기).
- 바닥 빨간 압력 버튼, 벽의 버튼(총으로 맞춰야 작동 — 칠판 힌트로 안내).
- 천장에서 내려오는 가시 블록.
- 체력 회복(빨간 십자 상자), 탄약 상자(초록), 병 모양 아이템.
- (기억) 후반에 자동차·헬기가 나와 목표를 밀어버릴 수 있었음.

## HUD·조작
- 위 가운데: 골드, 목표 아이콘 + "n/N". 오른쪽 위: 일시정지, 원형 레이더(점으로 위치 표시).
- 왼쪽 위: 체력바(+ 열쇠 아이콘). 가운데 작은 조준점.
- 모바일 버튼: 왼쪽 이동 스틱, 오른쪽 `공격` `조준` `점프` `달리기` `무기변경`, 상호작용 시 손 아이콘.
- 일시정지 메뉴: 계속하기 / 다시하기 / 레벨선택 / 회전감도 / 게임종료.
- 로딩 화면: 벤치에 비목표 셋 + 목표 하나가 앉아 있는 그림 (우리는 새로 만든다).

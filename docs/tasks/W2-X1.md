## 목적
검수자가 게임에 들어간 **적, 무기, 픽업, 맵 사물**을 Studio에서 하나씩 돌려 보며 확인하는 별도 플레이스. 게임 코드는 그대로 두고, 게임이 쓰는 **같은 빌더 함수**를 불러서 보여 준다 (게임에서 바뀌면 갤러리도 자동으로 바뀜). 함께 모든 요소를 표로 정리한 `docs/CATALOG.md`를 자동 생성한다.

## 할 일
1. **`gallery.project.json`**: `ReplicatedStorage.Shared` = `src/shared`, `ServerScriptService.Gallery` = `src/gallery/server`, `ServerStorage.GameServer` = `src/server` (맵 키트·MapBuilder를 쓰기 위해, 게임 스크립트는 실행되지 않도록 `Main.server.luau`를 **포함하지 않거나** 비활성화 — 방법을 PR에 설명), `StarterPlayer.StarterPlayerScripts.Gallery` = `src/gallery/client`. `Workspace.StreamingEnabled = false`.
2. **전시장 (서버)**: 넓은 평평한 바닥에 카테고리별 줄로 받침대를 놓고 각 요소를 하나씩 세운다.
   - **적**: `Config/Enemies`의 모든 종류 (`Red`, `White`, 데이터만 있는 `Bomb` `Raptor` `Missile`은 "(미구현)" 표시). Humanoid는 앵커해서 쓰러지지 않게.
   - **무기**: `Config/Weapons.Order`의 모든 무기의 `worldModel` (월드 모델) — 받침대 위에서 천천히 회전.
   - **픽업**: 무기 픽업 `display`, 체력·탄약 `supplyDisplay`.
   - **맵 사물**: `Kit`의 조각을 하나씩 — 바닥 타일, 벽(Low/Mid/High × Brick/Glass/Concrete), 계단, 플랫폼, 다리, 상자, 상자 더미, 드럼통, 나무, 울타리(pen), 칠판, 가로등, 벤치, 받침(plinth), 시작 방(문 포함). 각 조각을 작은 MapSpec으로 만들어 `MapBuilder.build`로 짓는다.
   - 각 받침대 위에 이름표 (BillboardGui): 한국어 이름 + 키 (예: `레드 · Enemy/Red`).
3. **목록 UI (클라이언트)**: 왼쪽 패널에 카테고리 탭(적 / 무기 / 픽업 / 맵 사물)과 항목 목록. 항목을 누르면 카메라가 그 요소로 부드럽게 이동해 천천히 공전하고, 오른쪽 정보 패널에 이름, 키, 정의 파일, 주요 수치(적: HP·속도·시야·공격, 무기: 피해·연사·탄창/예비·사거리)를 보여 준다. `이전`/`다음` 버튼과 ←/→ 키, 마우스 휠로 줌. 적은 `대기/걷기` 애니메이션 토글 버튼. 캐릭터는 생성하지 않거나 숨긴다 (Players.CharacterAutoLoads = false 등).
4. **목록 문서**: `tools/catalog/generate.luau` (Lune)가 Config와 Kit/EnemyBody를 읽어 `docs/CATALOG.md`를 만든다 — 표: 적(키, 이름, HP, 속도, 시야, 공격, 벌점, 구현 여부), 무기(키, 이름, 종류, 피해, 연사, 탄창/예비, 사거리, 획득 방법), 픽업, 맵 사물(Kit 함수, 설명, 높이), 소리 키(파일 `media/sfx/<키>.ogg` 존재 여부, ID 입력 여부), 스테이지(Id, 이름, 맵, 기준 시간, 목표 Base). 맨 위에 "자동 생성 — 직접 고치지 말 것"과 생성 방법.
5. **빌드 스크립트**: `tools/catalog/build_gallery.sh` → `rojo build gallery.project.json -o build/Gallery.rbxl` + 문서 생성.

## 다른 영역과의 약속 (바꾸지 말 것)
- 게임 코드(`src/shared`, `src/server`, `src/client`), `default.project.json`, `tools/check.sh`는 **수정 금지**. 빌더가 갤러리에 쓰기 불편하면 PR에 제안만.
- 순수 모듈은 그대로 `require`해서 쓴다.

## Studio 체크리스트 (검수자용, PR에 그대로 옮겨 적기)
1. `build/Gallery.rbxl`을 Studio에서 열고 Play.
2. 왼쪽 목록에 적 / 무기 / 픽업 / 맵 사물 탭이 보인다. Output에 빨간 오류가 없다.
3. 적 탭 → 레드 클릭: 카메라가 레드 앞으로 이동해 천천히 돈다. 오른쪽에 HP 30·속도 등. `걷기` 버튼으로 걷는 동작.
4. `다음`/→ 키로 화이트, 폭탄(미구현 표시) 등을 차례로 본다.
5. 무기 탭: 방망이, 권총, 저격총(+데이터만 있는 무기)이 받침대 위에서 돈다.
6. 픽업 탭: 무기 픽업, 체력 상자, 탄약 상자.
7. 맵 사물 탭: 벽 9종, 계단, 플랫폼, 다리, 상자, 드럼통, 나무, 울타리, 칠판, 가로등, 벤치, 시작 방.
8. `docs/CATALOG.md`를 열어 표 내용이 게임과 맞는지 훑어본다.

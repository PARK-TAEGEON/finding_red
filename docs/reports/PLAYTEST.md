# 플레이 검수 가이드 (v0.5)

자동 검사(빌드, 타입 검사, 테스트 약 4,500개, 맵 검사)는 모두 통과했어요. 아래는 **Studio에서 직접 봐야 하는 것**만 모았어요. 25~35분 걸려요. 이전 가이드는 `WAVE1_PLAYTEST.md`.

## 준비
1. `FindingRed.rbxl`을 Studio에서 **파일로 직접** 여세요 (기본 템플릿에 Rojo로 붙이면 바닥·스폰이 로비 위에 겹쳐요).
2. **View → Output** 창을 열어 두세요. 빨간 오류 줄이 가장 중요한 단서예요.

## A. 솔로 (Play)
| # | 할 일 | 정상이면 |
|---|---|---|
| 1 | Play | 로비. 아래에 레벨 선택 격자 "LEVEL 1" + 칸 1·2·3, 칸마다 도장 3칸. 2·3은 회색 자물쇠 |
| 2 | `준비!` → 1 칸 | 투표 후 **Loading 화면**(진행 막대, 벤치 그림, 팁 한 줄) |
| 3 | 로딩 끝 | **시작 방** 안. 1인칭, 앞 벽에 칠판(LEVEL 1-1 / 레드 1마리 잡기 / 힌트), 위에 "문을 열고 들어가세요! (20)". 아직 총은 안 나감 |
| 4 | 흰 문으로 걸어가기 | 5스터드 안에서 큰 ✋ 버튼 + "E: 문 열기" |
| 5 | `E` (또는 클릭) | 문 열리는 소리, 문이 옆으로 미끄러져 사라짐, "시작!", 이제 총이 나감. 타이머도 이때부터 |
| 6 | (다시 하기에서) 아무것도 안 하고 20초 | 문이 자동으로 열림 |
| 7 | 레드에게 다가가기 | "!" → **레드가 다가와서 때림**, 맞을 때 화면 전체가 잠깐 빨개짐. 뒤로 걸어가면서 쏘면 거리 유지 가능 |
| 8 | 레드 처치 | **그 자리에서 힘없이 무너져 누움** (멀리 안 날아감). 시체가 바닥에 남고, 걸어서 통과됨 |
| 9 | "미션 성공!!" | 결과 화면 뒤로 **시체가 그대로 보임**. 버튼 `다시하기` / `다음` / `로비로` |
| 10 | 경기장 빨간 십자 상자 | 체력이 깎인 상태로 걸어가면 "체력 +N". 체력이 가득하면 안 먹어짐 |
| 11 | `다음` → 1-2 | 로딩 → 시작 방 바닥에 **저격총**, 걸어가면 획득 ("저격총 획득! (3번 키)") |
| 12 | 1-2 문 열기 | 바로 정면에 저격 레인 끝 탑이 보임. 탑·옥상 레드는 **뛰어내리지 않고** 제자리 근처에서 버팀 |
| 13 | 탑 레드를 권총으로 한 발 | 탑 위에서 버티고, 아래로 안 떨어짐 → 저격총으로 처치 |
| 14 | 1-3 (밤) | 시작 방에 탄약 상자. 화이트 무리 사이 레드. 화이트를 총으로 죽이면 빨간 X + "깔끔 도장 실패" |
| 15 | 시작 방으로 다시 들어가서 숨기 | 벽 너머 레드에게 맞지 않음 |
| 16 | 쓰러지기 | "쓰러졌어요!" 오버레이. 솔로면 10초 뒤 "미션 실패" |
| 17 | `P` (또는 `II`) | 일시정지, 감도 슬라이더, `계속하기`로 1인칭 복귀 |

## B. 2인 (Test → Clients and Servers → 2 Players)
| # | 할 일 | 정상이면 |
|---|---|---|
| 1 | 둘 다 준비 | 격자 칸 위에 투표 점, 함께 로딩 → 같은 시작 방 |
| 2 | 한 명만 문 열기 | 둘 다 판 시작. 상대 화면에서도 문이 열리는 게 보임 (조금 끊겨 보일 수 있음) |
| 3 | 서로 보기 | 상대 손에 **무기**가 보이고, 총알 궤적이 그 총구에서 나감 |
| 4 | 저격총·체력 상자 | 한 명이 먹어도 다른 사람은 따로 먹을 수 있음 |
| 5 | 상대 옆에서 레드 처치 | 시체가 쓰러지는 첫 1초 동안 팔다리가 떨리거나 늘어나는지 |
| 6 | 한 명 쓰러짐 → `E` 3초 | 부활 (HP 50) |
| 7 | 판 중 한 명 나가기 | 목표 수 감소, Output 오류 없음 |

## C. 모바일 (Device 에뮬레이터)
- 시작 방에서 문 앞에 가면 ✋ 버튼 터치로 열림.
- 오른쪽 버튼 `공격` `조준` `무기변경` `달리기` `점프`.

## 결과 알려주기
- **안 되는 것**: "A-12 탑 레드가 떨어짐"처럼 번호 + 한 줄
- **Output 빨간 줄** 복사
- **느낌**: 레드가 너무 세다/약하다, 쓰러지는 모습이 어색하다, 문 위치가 불편하다 등

## 알려진 한계
- 쓰러지는 각도·밀리는 힘은 추정값이라 눈으로 보고 조정 필요
- 문 열림은 서버 연출이라 다른 플레이어 화면에서 살짝 끊길 수 있음
- 시작 방 조명이 벽을 살짝 비춤
- 모바일 회전 감도 미적용, 모바일 점프 버튼 중복
- Esc는 Roblox 메뉴가 가져갈 수 있어서 일시정지는 `P`/`II`

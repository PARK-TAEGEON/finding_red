# 1차 웨이브 플레이 검수 가이드

자동 검사(빌드, 타입 검사, 테스트 1,800여 개, 맵 검사)는 모두 통과했어요. 아래는 **Studio에서 직접 눌러 봐야 하는 것**만 순서대로 모은 거예요. 30~40분 걸려요. 에이전트별 상세 체크리스트는 `A.md`~`D.md`에 있어요.

## 준비
1. `FindingRed.rbxl`을 Studio에서 열어요. (또는 저장소에서 `rojo serve` 후 Rojo 플러그인으로 연결)
2. 효과음 ID를 아직 안 넣었으면 소리 없이 진행돼요. 정상이에요.
3. **View → Output** 창을 열어 두세요. 빨간 오류가 뜨면 그 줄을 복사해 두는 게 가장 중요해요.

## A. 솔로 한 바퀴 (Play 버튼)
| # | 할 일 | 정상이면 |
|---|---|---|
| 1 | Play | 로비 과녁 위에 서서 큰 칠판을 봄. 3인칭, 커서 보임. 위에 골드 2000, 아래 `준비!` `친구 초대` 버튼 |
| 2 | `준비!` | 투표 카드 `LEVEL 1-1 첫 사냥` → 2초 뒤 자동 진행 |
| 3 | 카운트다운 | 스테이지로 이동, 큰 숫자 5→1, 칠판에 "LEVEL 1-1 / 레드 1마리 잡기 / 힌트". 카운트다운 중엔 총이 안 나감 |
| 4 | "시작!" | 1인칭, 마우스 잠김, 조준점, 오른쪽 아래 권총+팔. 위에 `0/1`, 오른쪽 위 레이더에 빨간 점, 왼쪽 위 체력바 |
| 5 | 레이더 따라 레드 찾기 | 레드(빨간 몸, 노란 눈, 뿔)가 구석에서 배회. 다가가면 머리 위 "!" → 도망 → 잠시 느려짐(지침) |
| 6 | 권총으로 2발 | 흰 X 히트마커, 레드 체력바 감소, 2발째에 날아가며 쓰러짐 |
| 7 | 결과 | "미션 성공!!", 도장 3개가 하나씩 찍힘, `+골드`, `다음 스테이지 / 다시하기 / 로비로` |
| 8 | `다음 스테이지` | 바로 1-2 카운트다운 |
| 9 | 1-2: 스폰 옆 저격총 | 받침 위에서 돌고 있음 → 걸어가면 자동 획득, `3`번 키로 꺼냄 |
| 10 | 우클릭 스코프 | 검은 원형 스코프, 십자선. 북쪽 탑 꼭대기 레드를 한 방에 |
| 11 | 옥상 레드 | 계단으로 올라가 잡기 (서쪽 8, 동쪽 12 높이) |
| 12 | 1-3 (밤) | 가로등 켜진 어두운 맵. 화이트(흰 몸, 검은 바이저)가 쫓아와 때림 → 화면 가장자리 빨갛게, 체력 감소 |
| 13 | 화이트를 방망이로 (`1`번) | 밀려나며 2초 기절, 피해 없음 |
| 14 | 화이트를 총으로 죽이기 | 빨간 X + "깔끔 도장 실패" 토스트. 결과에 `깔끔` 도장 없음 |
| 15 | 일부러 맞아서 쓰러지기 | "쓰러졌어요!" + 30초 카운트, 느리게 기어감. 솔로면 10초 뒤 "미션 실패" |
| 16 | `P` 키 (또는 화면 `II`) | 일시정지, 커서 보임, 감도 슬라이더로 회전 속도 바뀜, `계속하기`로 복귀 |
| 17 | `Shift` | 달리기 토글 (빨라짐) |
| 18 | 로비로 돌아오기 | 투표 카드에 도장 개수 표시, 다음 스테이지 해금 |

## B. 2인 협동 (Test 탭 → Clients and Servers → Players 2 → Start)
| # | 할 일 | 정상이면 |
|---|---|---|
| 1 | 둘 다 준비 | 즉시 투표, 표 수가 양쪽에 실시간 |
| 2 | 1-1 시작 | 목표 `0/2`, 레이더에 동료 초록 점, 서로 총알 궤적이 보임, 아군 피해 없음 |
| 3 | 1-2 저격총 | 한 명이 주우면 **그 사람 화면에서만** 사라짐, 다른 사람도 따로 주울 수 있음 |
| 4 | 한 명 쓰러지기 | 다른 사람 화면에 "쓰러졌어요" 토스트 → 6스터드 안에서 `E` 3초 → HP 50으로 일어남 |
| 5 | 둘 다 쓰러지기 | 10초 뒤 실패 |
| 6 | 판 중 한 명 창 닫기 | 목표 수가 내려감, 이미 채웠으면 즉시 성공, Output에 오류 없음 |

## C. 모바일 (Test 탭 → Device 에뮬레이터에서 휴대폰 선택)
- 오른쪽에 `공격` `조준` `무기변경` `달리기` `점프` 버튼. 쓰러진 동료 근처에서 `부활` 버튼.
- 알려진 문제: 점프 버튼이 Roblox 기본 것까지 두 개. 화면 회전 감도는 모바일에 적용 안 됨.

## D. 저장 (선택, 별도 테스트 플레이스에서)
1. 이 파일을 다른 이름의 새 게임으로 게시 → Game Settings → Security → **Enable Studio Access to API Services** 켜기.
2. `src/shared/Config/Game.luau`의 `StudioUseDataStore`를 `true`로 바꿔서 빌드 (이건 커밋하지 않기).
3. 1-1 클리어 → 정지 → 다시 Play: 골드, 도장, 해금, 감도가 유지되면 성공.

## 결과 알려주는 방법
아래 세 가지만 주시면 돼요. 길게 설명 안 하셔도 돼요.
- **안 되는 것**: 몇 번 단계에서 무엇이 이상했는지 (예: "A-6 맞아도 체력바 안 줆")
- **Output 오류**: 빨간 줄 복사 (가장 중요)
- **느낌**: 레드가 너무 빠름/느림, 총이 약함, 맵이 넓음 같은 체감

스크린샷이나 짧은 화면 녹화가 있으면 더 좋아요.

## 알려진 한계 (고칠 예정)
- 모바일 화면 회전 감도 미적용, 모바일 점프 버튼 중복
- Esc는 Roblox 메뉴가 가져갈 수 있어서 일시정지는 `P`/`II`
- 화이트는 상자 위에 올라간 플레이어를 못 때림
- 몬스터 시체가 2.5초 동안 남아 플레이어를 살짝 밀 수 있음
- 열쇠를 든 화이트가 죽어도 열쇠가 아직 안 떨어짐 (2차 기믹 웨이브에서)
- 라이플·샷건·수류탄·로켓은 데이터만 있음 (2차)
